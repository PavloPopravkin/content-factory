# Content Factory - манифест

stage: active-dev
refactor-appetite: high
last-reviewed: 2026-10-25

## Что это / для кого
Open-source контент-фабрика для фондов и компаний: люди скидывают фото, видео, голосовые; AI по инструкциям
организации собирает посты, сторис, рилсы и публикует во все каналы. Первые пользователи: благотворительный фонд и компания с десятками страниц.

## Инварианты
- План публикаций владеет только фабрика; внешний планировщик исполняет "сейчас".
- `tenant_id` в каждой сущности; ключи соцсетей только у publisher; AI-куратор без ключей, в песочнице.
- Журнал доставки до внешнего вызова; потерянный ответ = unknown, без слепого повтора.
- Факты в текстах только с происхождением из присланного или прошлых постов.

## Целевая архитектура
- Postiz как исполнитель за адаптером `Publisher`, прямые адаптеры Telegram и Meta. Критерий: smoke всех типов постов.
- Второй tenant проходит полный цикл на чистой установке по README. Критерий: без личного окружения автора.

## Non-goals
- Свой OAuth и публикация всех сетей с нуля.
- SPA-админка; хватит FastAPI + htmx.

## Стек
Python 3.12, FastAPI, SQLite WAL, ffmpeg/Pillow, Whisper, headless Claude/Codex, Postiz API, Docker compose.
